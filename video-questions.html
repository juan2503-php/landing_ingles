Video Questions

Watch the video and explore the 1st conditional questions about web scenarios.

1. What will happen if the user closes the website by mistake?
The system will save their data.
2. What will the website show if the interactive org-chart fails to load?
It will show a static image.
3. How will the system react if a visitor clicks the same button ten times quickly?
It will ignore the extra clicks.
4. How will the user know if the server goes down during a critical process?
They will receive an email.
5. What will happen to the animations if someone uses a very old web browser?
They won't work properly.
6. Who will fix the issue if the database deletes a user's profile accidentally?
The administrator will fix it.
7. What will the security system do if a hacker tries to log in?
It will block their IP address.
8. What will the website display if the internet connection drops suddenly?
It will display an offline message.
9. Which features will break if a user turns off JavaScript in their browser?
The interactive features will break.
10. How will the design change if the user switches the device to dark mode?
The colors will adjust automatically.
