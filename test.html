General Grammar Guide

ZERO CONDITIONAL

We use the Zero Conditional for facts, scientific truths, natural laws, and things that always happen when a specific condition is met.

Structure IF + PRESENT SIMPLE, PRESENT SIMPLE

Example: If you connect the charger, the computer charges.

CONDITION
If you connect the charger
↓
RESULT
the computer charges

Zero Conditional Sentence
If you connect the charger, the computer charges.
CONDITION
If you connect the charger
→
RESULT
the computer charges
English Explanation

The condition is “If you connect the charger” and the result is “the computer charges”. Both clauses are in the Present Simple because the outcome occurs consistently each time the action is performed.

Explicación en Español

Explicación: Cuando conectas el cargador, el computador carga. La acción ocurre cada vez que se cumple la condición.
