🟢 Zero Conditional
Zero Conditional
Se usa para hablar de situaciones que siempre pasan o hechos generales.
If + presente simple, presente simple.
  • If you heat water, it boils.
    → Si calientas agua, hierve.
  • If I eat too much, I feel sick.
    → Si como demasiado, me siento mal.
Clave: Siempre ocurre.

🔵 First Conditional
First Conditional
Se usa para hablar de algo que puede pasar en el futuro si se cumple una condición.
If + presente simple, will + verbo.
  • If it rains, I will stay home.
    → Si llueve, me quedaré en casa.
  • If I study, I will pass the exam.
    → Si estudio, aprobaré el examen.
Clave: Puede ocurrir en el futuro.

Diferencia fácil
Zero Conditional vs. First Conditional
Una regla sencilla para saber cuándo usar cada condicional:
Zero

Siempre ocurre

If you heat ice, it melts.
First

Puede ocurrir

If I study, I will pass.
